# Drip Shop Live

> Drip Shop Live (Flourish Cares, Inc. DBA Drip Shop Live) is a livestream shopping
> marketplace and community for collectors — trading cards (Pokémon, Magic, Yu-Gi-Oh!,
> Digimon, sports cards), memorabilia and other collectibles. Sellers host live streams to
> run realtime auctions, box breaks, pull games and giveaways; buyers watch, bid, chat and
> check out in-stream, and earn Drip Coin rewards. The platform is crypto-native (wallet,
> Solana, Base, and a Farcaster mini-app) alongside Stripe and PayPal payments. It runs on
> a single first-party GraphQL API (introspection enabled) that powers the iOS, Android and
> web clients; there is no separate public developer program.

## API

- [Drip Shop Live GraphQL endpoint](https://api.dripshop.live/graphql): Single GraphQL API (268 queries, 283 mutations, 56 subscriptions). Bearer-token auth; `query { health }` is public.
